# 标注格式

用 Excel / Google Sheet 建一张表，**第一行照抄这些英文列名**，一句一行填。填完导出 UTF-8 的 TSV

| 列名 | 这一列填什么 | 例子 |
|---|---|---|
| `uid` | 编号，`表-类别-序号`，同表内不重复 | `A-NEO-001` |
| `table` | 这句来自哪张表：`A`（CSM）或 `B`（新爬） | `A` |
| `category` | 噪声类别，**只填一个**：`HOM`谐音 / `PYA`拼音缩写 / `NEO`新词 / `MIX`中英混杂 | `NEO` |
| `src_noisy` | 原句（带噪声，已删掉@用户名/网址/个人信息） | `周末加班，真的是牛马命` |
| `src_clean` | 干净版：**只把噪声词换成标准说法，别的一个字都不改** | `周末加班，真的是打工人的命` |
| `ref_en` | 英文翻译，**对着 `src_noisy` 翻**（不是对着干净版），保留原语气 | `Working overtime on weekends — the life of a corporate drone` |
| `noise_span` | 原句里那个噪声词，多个用 `‖` 隔开 | `牛马` |
| `noise_gold_en` | 这个噪声词的正确英译（可加至多3个也算对的说法，`‖` 隔开） | `corporate drone ‖ working stiff ‖ wage slave` |
| `noise_std` | 噪声词的标准写法（就是你在干净版里换上去的词） | `打工人` |
| `source_meta` | 表B填：平台+日期（如 `xhs 2026-07-22`）；表A填 CSM 原编号 | `CSM fun_0515` |

> **一条最重要的规矩**：`ref_en` 对着**噪声原句**翻，`src_clean` **只换噪声词**——这两条错了数据就废了。

---

### 四类怎么分（拿不准时看这里）

| 类别 | 例（噪声 → 标准） |
|---|---|
| `HOM` 谐音 | 蚌埠住了→绷不住了、灰常→非常 |
| `PYA` 拼音缩写 | yyds→永远的神、xhs→小红书 |
| `NEO` 新词 | 牛马→打工人、绝绝子→绝了 |
| `MIX` 中英混杂 | get→学会、Citywalk→城市漫步 |

一句里混了两类噪声的，这句不要，跳过。

> **为什么一句只填一个类别**：我们最后要比"哪类噪声伤害最大"。一句的退化分数是整句一次算出来的、**拆不开**——要是一句同时标谐音+缩写，这份退化会被同时算进两类、分不清到底是谁造成的，"谁伤害大"就没法比了。所以一句只留一类，混两类的整句跳过（记 `MULTI`）。
> （注：一个**词**同时像谐音又像新词，是另一回事——那个照§前面的两步还原选主类即可，不算"混两类"。）

---

### 遇到单个词 / 短语怎么办（评论区很多）

- **原文什么颗粒度就翻成什么颗粒度**：词→词、短语→短语，**别脑补上下文把它扩写成整句**。
- **留不留就看一条**：这个词/短语单独拎出来，你能确定它啥意思吗？能→照翻；只能靠猜（如光一个「牛马」，定不了是牲畜还是打工人）→ 跳过。

| 原文 | ✅ 这样翻 | ❌ 别这样 |
|---|---|---|
| `yyds！` | `The GOAT!` | ~~He is forever the god of this field~~ |
| `绝绝子` | `Absolutely amazing` | ~~This dish is absolutely amazing~~（凭空加"这道菜"） |
